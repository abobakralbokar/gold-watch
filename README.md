# راصد الذهب

لوحة متابعة لحظية لسعر جرام الذهب بالريال السعودي وفي صنعاء وعدن، مع التوقعات والمستويات والتنبيهات.

- `page.html` — المصدر الأساسي (نسخة الأرتيفاكت داخل claude.ai).
- `index.html` — نسخة الموقع المستقل، تُبنى من `page.html` عبر `python3 build.py`.
- `data/forecast.json` — التوقعات والسيناريوهات والمستويات والأحداث (تُحدَّث أسبوعيًا وبعد الأحداث الكبرى).
- `data/fx.json` — أسعار صرف صنعاء وعدن وفوارق السوق (تُحدَّث يوميًا).
- `data/monitor.json` — آخر فحص تلقائي للسعر.
- `data/alerts.json` — سجل التنبيهات عند كسر المستويات.

السعر اللحظي يُجلب من `xaus.com` مباشرة في المتصفح (كل 30 ثانية). الصفحة لا تحتاج أي خادم.
